# 金铲铲 S18「羁绊天梯」海克斯辅助工具

一个纯前端的 React + TypeScript + Vite 单页应用，用于求解以下优化问题：

- **羁绊数量最大化（Max Traits）**：在限定人口与转职纹章数量下，凑出激活通用（general）羁绊数量最多的阵容。

计算在 Web Worker 中执行，不会阻塞界面；支持进度显示、中途取消、渐进式渲染（先贪心近似解，再回溯精调）。

## 快速开始

```bash
npm install
npm run dev
```

打开终端输出的本地地址（默认 `http://localhost:5173`）即可使用。项目内置了 `champions.json` 与 `traits.json` 示例数据，启动后立即能看到界面并直接计算。

生产构建：

```bash
npm run build
npm run preview
```

## 技术栈

- React 18 + TypeScript（严格模式）
- Vite
- Tailwind CSS（通过 Play CDN 引入，避免额外构建依赖）
- Zustand（状态管理 + localStorage 持久化）
- Lucide React（图标）
- 原生 Web Worker（不依赖 comlink）

## 如何替换自己的数据

页面左侧底部提供 **导入数据** 区域，可分别上传你自己的 `champions.json` 与 `traits.json`，上传后立即生效。

也可以直接替换项目根目录下的两个 JSON 文件，再重新 `npm run dev` / `npm run build`。数据格式必须满足：

```json
// champions.json
[
  { "id": "lux", "name": "拉克丝", "cost": 5, "traits": ["大元素使"], "slots": 1 }
]

// traits.json
[
  { "id": "spirit", "name": "灵魂莲华", "thresholds": [3, 5, 7], "hasEmblem": true, "emblemName": "灵魂莲华纹章", "type": "general" }
]
```

关键约定：

- `champions[].traits` 中的字符串必须与 `traits[].name` **完全一致**（包括中文）。
- `traits[].type` 为 `"general"` 或 `"exclusive"`，只有 `general` 计入羁绊数量目标。
- 若你的 `traits.json` 缺少 `type` 字段，加载器会依据 S18 专属羁绊名单自动推断；其中用户可选择的 20 个转职纹章羁绊会被强制识别为 `general`。
- 默认数据已为「大元素使」提供 `effect.targetTraits`（9 个元素羁绊）。若导入的数据缺失 `effect`，加载器会尝试从拉克丝自身其它羁绊自动推导。

## 算法简述

### 通用数据结构

- 每个 `general` 羁绊分配一个 BigInt 位；英雄的羁绊集合压缩为位掩码。
- 羁绊计数用 `Uint8Array` 追踪，人口用 `Uint8Array` 记录每个候选英雄的占位。
- 拉克丝双倍效果不参与回溯中的计数维护，只在「叶子评估」时叠加，避免重复计算。

### 求解器：MaxTraitsSolver

1. **预处理**：先放入锁定英雄；按「general 羁绊数 / slots」的密度降序排列候选；检测拉克丝与用户选择的转职纹章。
2. **Phase 1 贪心**：best-first 贪心，每次选择使激活羁绊数提升最大的英雄，快速得到下界。
3. **Phase 2 回溯分支定界**：DFS 遍历子集，剪枝包含：
   - 人口剪枝（`used + slots > 人口`）；
   - 上界剪枝（当前激活数 + 剩余英雄覆盖上界 + 转职激活上界 + 拉克丝双倍裕量 ≤ 当前最优）；
   - 对称剪枝（同费用同羁绊的英雄按索引去重）；
   - 转职上界剪枝（剩余纹章最多还能激活的新羁绊数）。
4. **Phase 3 局部搜索**：对最优解做单英雄替换，接受羁绊数增加或相同但费用更高的替换，迭代至收敛。
5. **Tie-breaker**：羁绊数相同时选择总费用更高者。

求解器不受英雄费用限制，任何费用的英雄都可以使用；左侧 **锁定英雄** 始终上场。

## 拉克丝「大元素使」机制

- 拉克丝识别：`id === "lux"` 或 `traits` 包含「大元素使」。
- 用户可在左侧下拉选择双倍羁绊：
  - **自动最优**（默认）：算法遍历所有 `targetTraits` 与「不触发」，选择使目标函数最大者；
  - **不触发双倍**：拉克丝不提供任何 general 羁绊计数；
  - **指定羁绊**：拉克丝对该羁绊提供 2 点计数。
- 「大元素使」本身为 `exclusive`，不计入羁绊数量；但其双倍效果会影响 `general` 羁绊的计数与层级分。
- 若阵容不含拉克丝，双倍配置自动失效，并在结果区给出灰色提示。

## 转职纹章选择

- 可选择的转职纹章羁绊固定为 20 个：灵魂莲华、地狱火、约德尔人、永恒之森、黑荆棘、花仙子、野兽之灵、绝命花妖、月食、魔女、法师、狂战士、斗士、迅捷射手、猎手、裁决使、重装战士、护卫、主宰、神谕者。
- 初始化时不选择任何纹章；同一类型纹章可多选（数量 > 1）。
- 所有类型纹章的选择总数不能超过「转职纹章数量」上限。
- 最终评估时，已选择的纹章会直接叠加到对应羁绊计数上（每个纹章 +1）。
